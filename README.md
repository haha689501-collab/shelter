# 쉼터 3D

브라우저에서 걸어 다니며 쉬는 3D 힐링 공간입니다.
설치가 필요 없고, `config.js`만 고치면 어느 학교·기관·행사에서도 쓸 수 있습니다.

| 장소 | 할 수 있는 일 |
|---|---|
| 🌲 소나무 언덕 | 앉아서 숨 고르기(호흡 안내), 응원 쪽지를 나무에 걸기, 쪽지 읽기 |
| 🌱 작은 온실 | 함께 물 주기 → 모두가 준 물 횟수만큼 가운데 화분이 자라고, 10번이 넘으면 꽃이 핌 |
| ☕ 창가 카페 | 창가에 앉기, 빗소리 켜기, "수고했어" 보내기 |
| 🎹 음악실 | 도·레·미·솔·라 건반 (어떻게 눌러도 어울리는 5음 음계). 함께 모드에서는 다른 사람 소리도 들림 |
| 🌌 별빛 운동장 | 누워서 별 보기, 소원 별 띄우기, 하늘을 도는 새 |

공통으로 손 흔들기와 인사하기가 있고, 익명 별명(예: "포근한 수달")이 자동으로 붙습니다.

---

## 1. 바로 열어 보기 (혼자 모드)

`index.html`을 더블클릭하면 열립니다. 3D 라이브러리를 인터넷에서 불러오므로 인터넷 연결이 필요합니다.

- 이때는 쪽지·소원·카운터가 **이 브라우저에만** 저장됩니다.
- 조작: 땅을 클릭하면 이동, W A S D 또는 방향키로 이동, 드래그로 시점 회전, 휠로 확대·축소

## 2. 우리 공간으로 바꾸기: `config.js`

| 항목 | 설명 |
|---|---|
| `title`, `subtitle` | 공간 이름과 소개 문구 |
| `places` | 장소 목록. 이름(`name`), 설명(`desc`), 위치(`position`)를 바꾸거나, 장소를 지우거나 같은 종류를 더 넣을 수 있음 |
| `theme` | 하늘·땅·길 색 |
| `bannedWords` | 금지어 목록 |
| `maxTextLength` | 글자 수 제한 (기본 40자. 바꾸면 `schema.sql`의 `40`도 같이 바꾸기) |
| `roomCapacity` | 방 하나의 최대 인원 (넘으면 `?room=main-2`처럼 다른 방으로 안내) |

## 3. 여러 명이 함께 쓰기 (Supabase + Vercel)

1. **Supabase**에서 프로젝트를 만들고, `supabase/schema.sql`을 SQL Editor에서 실행합니다.
2. Supabase의 Project Settings > API에서 **Project URL**과 **공개용 키(anon / publishable)**를 복사해 `config.js`의 `supabase`에 넣습니다.
   - ⚠ `service_role`(secret) 키는 **절대 넣지 마세요.** 이 키가 있으면 모든 보안 규칙을 건너뛸 수 있습니다.
   - 공개용 키는 브라우저에 노출되어도 괜찮도록 설계된 키입니다. 실제 보안은 `schema.sql`의 RLS 규칙이 담당합니다.
3. **Vercel**에 이 폴더를 그대로 올립니다. 빌드 설정은 필요 없습니다(정적 사이트).
4. 배포된 주소를 공유하면 같은 방에 들어온 사람끼리 서로의 아바타, 인사, 건반 소리, 새 쪽지와 별을 실시간으로 봅니다.

방은 주소 뒤에 `?room=이름`을 붙여 나눌 수 있습니다(예: `?room=class1`). 방마다 쪽지와 카운터가 따로 저장됩니다.

## 4. 운영과 안전

- **글 숨기기:** Supabase 대시보드 > Table Editor > `shelter_messages`에서 해당 글의 `hidden`을 `true`로 바꾸면 더 이상 보이지 않습니다. 이미 접속해 있는 사람 화면에서는 새로고침한 뒤에 사라집니다.
- **이미 들어 있는 보호 장치:** 글자 수 제한(DB에서도 검사), 금지어, 같은 사람의 연속 등록 제한(브라우저 쪽), 남의 글 수정·삭제 불가(RLS), 카운터는 +1만 가능
- **아직 없는 것 (수업 과제로 좋음):** 서버 쪽 도배 방지(rate limit), 로그인, 신고 버튼, 관리자 화면
- 개인정보(이름·연락처)를 적지 말라는 안내가 입력창에 표시됩니다.
- 실제 건물 배치·사진·로고는 쓰지 않았습니다. 특정 장소를 본떠 꾸밀 때는 내부 구조를 그대로 옮기지 말고, 공개 전에 기관의 승인을 받으세요.
- Vercel 무료(Hobby) 플랜은 비상업용입니다. Supabase 무료 플랜은 동시 실시간 접속 수에 상한이 있으니, 큰 행사에 쓰기 전에 공식 요금 페이지를 확인하세요.

## 5. 파일 구성

```
index.html          화면 구조
style.css           화면 디자인
config.js           ← 여기만 고치면 됨
app.js              3D 장면, 상호작용, 저장, 실시간 동기화
supabase/schema.sql 테이블과 보안 규칙
```

## 6. 팀으로 확장하기 (아이디어)

| 역할 | 해 볼 만한 일 |
|---|---|
| 기획·데이터 | 방문 시간대, 인기 장소를 보는 운영 대시보드 |
| 디자인·콘텐츠 | 새 장소 디자인, 계절 테마(벚꽃·눈), 배경 음악 |
| 구현 | 새 장소 종류 추가, 모바일 조이스틱, 로그인 |
| 보안·품질 | 도배 방지, 신고 기능, RLS 점검, 접속 폭주 테스트 |
