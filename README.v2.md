# 쉼터 3D — v2 (해 질 녘 힐링 공간)

산사 메타버스(sansatemple.com)와 나란히 놓고 보면서, 같은 수준으로 보이게 하려면 무엇이 필요한지
하나씩 채운 버전입니다. **원본 파일은 그대로 두고 새 파일로 만들었습니다.**

| 열어 보기 | 파일 |
|---|---|
| 예전 것 | `index.html` → `app.js`, `style.css` |
| 새 것 | `index.v2.html` → `app.v2.js`, `style.v2.css` |

`config.js` 는 둘이 같이 씁니다. 비교 화면은 `_비교샷/` 폴더에 있습니다.

---

## 1. 산사와 우리 것의 차이 (무엇 때문에 달라 보였나)

| 항목 | 산사 | v1 (예전) | v2 (지금) |
|---|---|---|---|
| 표면 | 나무 · 돌 · 회벽 · 기와 사진을 색/요철/거칠기 3종으로 입힘 | 단색 | 같은 3종을 **코드로 그려서** 입힘 (외부 파일 0개) |
| 그림자 | 있음 | 없음 | 있음 (부드러운 그림자) |
| 사람 | 전용 3D 모델(.glb) | 캡슐 + 공 | 머리 · 몸통 · 팔(어깨·팔꿈치) · 다리(엉덩이·무릎) · 신발 |
| 시간대 | 따뜻한 낮~해 질 녘 | 어두운 밤 | **해 질 녘(골든아워)** + 단풍 |
| 사람들 | 여럿이 오감 | 나 혼자 | NPC 5명 + 강아지 · 고양이 |

> 핵심: **모델을 잘 만드는 것보다 "표면 + 그림자 + 빛의 색"이 분위기의 8할**입니다.
> 같은 공간도 빛을 밤에서 해 질 녘으로 바꾸면 "공동묘지"가 "힐링 공간"이 됩니다.

## 2. v2 에 들어간 것

**분위기**
- 해 질 녘 하늘(3단 그라데이션 + 지는 해 + 노을 구름), 금빛 키 라이트, 따뜻한 안개
- 단풍 든 활엽수 + 소나무, 돌길 양옆으로 심은 꽃, 풀포기 9천 포기(바람에 흔들림)
- 먼 산은 원뿔이 아니라 **능선 잡음으로 빚은 지형** (해 드는 쪽이 밝고, 군데군데 단풍)
- 석등은 **사람이 가까이 가면 환해집니다** (점광원 2개를 가장 가까운 등으로 옮겨 씀)

**공간**
- 광장 가운데 **연못** — 분수 물줄기, 연잎과 연꽃, 잉어 세 마리, 걸터앉는 돌 테두리
- 온실 화분은 잎을 한 장씩 만든 식물(넓은 잎 · 허브 · 다육이)
- 물주기는 **물뿌리개가 기울어** 물줄기가 쏟아지고, 물방울이 튀고, 잎이 떨립니다

**사람**
- 얼굴: 이마가 보이는 머리선 + 또렷한 눈 + 옅은 눈썹 + 미소 (눈꺼풀을 얹으면 가면처럼 보여서 뺐습니다)
- NPC 5명이 장소 사이를 오가고, 가까이 가면 손을 흔들거나 인사합니다
- 한 명은 **강아지와 산책**, 카페 앞에는 **고양이**가 앉아 있습니다

**할 수 있는 일**
| 장소 | 동작 |
|---|---|
| 쉼터(광장) | 연못가에 앉기 · 물소리 켜고 끄기 |
| 소나무 언덕 | 숨 고르기 · 쪽지 걸기 · 쪽지 읽기 |
| 작은 온실 | 물 주기 |
| 창가 카페 | 창가에 앉기 · **음료 마시기** · 빗소리 · 수고했어 보내기 |
| 음악실 | 피아노 앞에 앉기 · 한 소절 쳐 보기 · **힐링 음악 듣기** |
| 별빛 운동장 | 누워서 별 보기(하늘이 밤으로 바뀌고 별 · 북두칠성 · 오로라 · 별똥별) · 소원 별 띄우기 |
| 멍냥 쉼터 | 간식 주기 · 쓰다듬기 · 공 던지기 (동물이 달려와 좋아합니다) |
| 북쪽 냇가 | 나무다리를 건너면 정자와 돌탑이 있는 숲 |

**소리** — 음원 파일 없이 전부 코드로 만듭니다
- 배경은 음악이 아니라 **자연 소리**: 바람, 나뭇잎 스치는 소리, 새 지저귐, 풀벌레(밤에 커짐), 아주 가끔 멀리서 울리는 풍경 소리
- 피아노: 도 레 미 파 솔 라 시 도 (다장조 한 옥타브)
- 물소리 · 빗소리 · 물 쏟아지는 소리

**조작**
- 클릭 이동은 **한 번에 최대 9걸음**까지만 (끝없이 걸어가지 않게), 클릭한 자리에 동그라미 표시
- 피아노 · 화분 · 건물 · 석등 · 연못에는 **몸이 묻히지 않습니다** (원형 충돌체 + 밀어내기)
- 벤치 · 의자 · 연못 테두리는 **올라앉는 높이**가 따로 있습니다

## 2-1. 물리(통과 방지)

- **원**(`{x,z,r}`)과 **상자**(`{x,z,hw,hd,회전}`) 두 가지 충돌체를 씁니다.
  건물처럼 벽이 있는 것은 **상자**로 막아야 합니다. 원을 여러 개 늘어놓으면 모서리로 새어 들어갑니다.
- 막힌 곳에 들어가면 **가장 가까운 벽 쪽으로** 밀어냅니다(매 프레임).
- 나무는 심을 때마다 줄기 굵기에 맞춰 원을 등록하고, 사람끼리는 서로 반반씩 밀어냅니다.

## 2-2. 먼 풍경 고르기

`app.v2.js` 위쪽의 `HORIZON` 한 줄로 바뀝니다 (config.js 에 `horizon` 을 두면 그 값이 우선).

| 값 | 보이는 모습 |
|---|---|
| `hills` (지금) | 넓은 들판 + 멀리 낮은 구릉과 숲 |
| `mountains` | 눈 덮인 봉우리가 있는 산줄기 |
| `none` | 지평선만 (가장 휑합니다) |

## 3. 수업에서 짚을 만한 지점

- **빛의 색이 분위기다** — 같은 모델도 은빛 달빛이면 무섭고, 금빛 저녁이면 따뜻합니다.
- **왜 네모난 풀은 종이상자처럼 보일까** → 끝으로 갈수록 좁아지는 띠로 바꾸면 풀이 됩니다.
- **속이 찬 원통은 뚜껑이 생긴다** → 연못 물이 안 보이던 이유. `openEnded` 로 바꿔야 합니다.
- **인스턴싱** — 풀 9천 포기, 길가 꽃 수백 송이를 그리기 명령 한 번으로.
- **해시의 함정** — `h >> 3` 은 값이 크면 음수가 되어 색 배열을 벗어납니다. `>>>` 를 써야 합니다.
- **묻힘 방지** — 충돌 처리가 없으면 캐릭터가 피아노 속으로 들어갑니다. 원 하나로도 충분히 막힙니다.

## 4. 더 올리고 싶다면

| 하고 싶은 것 | 방법 | 비용 |
|---|---|---|
| 진짜 사람 모델 | 캐릭터를 `.glb` 로 만들어 `GLTFLoader` 로 불러오기 | 파일 관리 · 용량 |
| 더 진한 분위기 | `EffectComposer` + Bloom · SSAO | 라이브러리 추가, 사양 |
| 사진 질감 | CC0 텍스처(ambientCG 등)로 교체 | 출처 표기 · 용량 |
| 휴대폰 대응 | `LOW` 분기에서 풀 수 · 그림자 해상도를 더 낮추기 | 없음 |
