# CLAUDE.md — 불멍 캠프 작업 지침

이 파일은 **다른 세션/계정의 Claude가 불멍 캠프를 똑같이 이어서 만들 수 있도록** 쓴 인수인계 문서입니다.
상위 폴더의 `../CLAUDE.md`(쉼터) 규칙을 그대로 따르고, 여기에는 **불멍에만 해당하는 것**을 적습니다.
사용자용 설명은 `README.md` 에 있습니다.

---

## 0. 한 줄 요약

별이 쏟아지는 밤, 숲속 모닥불 앞에서 **아무것도 안 해도 되는 시간**을 보내는 3D 공간.
쉼터와 같은 방식(three.js 한 개 · 외부 에셋 0개 · 소리도 코드 생성 · Supabase 함께 모드).
사용자가 원하는 결: **힐링 · 은은함 · 자연스러움.** 눈부시거나, 인위적이거나, 시끄러운 것은 계속 지적받았습니다.

## 1. 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조. **importmap 필수**(아래 '블룸'), 주소 끝 `/` 보정 스크립트, 불멍 모드 `#zen` |
| `app.js` (약 4,400줄) | 본체. **이 파일을 직접 고치면 됩니다** |
| `style.css` | 쉼터 `style.v2.css` 복사본 + **맨 아래에 불멍 덮어쓰기**(밤 색 · 불멍 모드 · 누웠을 때 · 휴대폰) |
| `config.js` | 이름 · 장소 4곳 · Supabase 공개 키 |
| `README.md` | 사용자용 안내 |

> 처음 만들 때는 임시 폴더에서 `app.v2.js` 의 일부를 잘라 붙여 조립했지만, **지금은 `app.js` 하나가 원본**입니다.
> 쉼터 `app.v2.js` 를 고쳐도 불멍에는 자동 반영되지 않습니다 (아바타 등 공통 부분은 필요하면 양쪽 다 고칠 것).

### app.js 읽는 순서
```
유틸 → 내 정보/방 코드/저장소(BUL- 접두어) → 렌더러·블룸 → 질감 공장(+bark·dirt)
→ 밤하늘(셰이더 · 별 8000개 · 별자리 8개 · 달) → 빛 → 지형(호수 · 데크) → 충돌(원·상자·타원)
→ 숲 · 풀 · 바위 → 모닥불(돌 · 장작 · 불꽃 셰이더 · 불티 · 연기 · 빛) → 자리 10개 · 장작더미 · 전구 줄
→ 천 무늬(stripeTex · quiltTex) · 꼬마전구(bulbString) → 벨 텐트 3개 → 해먹 → 호수 · 데크 · 반딧불이
→ 아바타(쉼터 것 + 마시멜로 · 기타 팔 자세) → 손에 드는 것 · 이웃(NPC) 3명
→ 소리 → 기타(카플러스-스트롱) → 효과 · 풍등 → 데이터 → 행동 → 불멍 모드 → 패널
→ 모습 고르기 · 대화(쉼터 것) → 네트워크 → 입력 → 시작 화면 → 루프(tick)
```

## 3. 사용자와 합의된 것 (어기면 다시 지적받음)

### 불멍 모드
- 버튼 · 이웃 · 다른 사람 · **의자와 통나무 벤치까지 숨기고 모닥불만** 남긴다
- 시간은 **하는 동안 띄우지 않고**, 끝낼 때 "🔥 불멍 N초 했어요"
- 카메라는 내 머리 옆 · 조금 앞(뒤통수가 화면을 가리면 안 됨), 노출을 0.9 로 낮춤
- 문장(`ZEN_LINES`)은 위로하는 말. "불꽃은 같은 모양으로…", "천천히 들이쉬고…"는 **빼 달라고 한 문장**

### 소리
- 모닥불: **따뜻하고 느긋한 '톡 · 타닥'** (1.2~3kHz, 간격 0.16~0.7초). **저음 '탁'은 금지** — "탁자 치는 소리"라고 함
- 귀뚜라미는 **잘 들리게**(불멍 중에도). 웅웅 하는 바탕 소리(바람 · 불 · 물결)는 작게
- **기타 소리는 내가 "기타 치기"를 눌렀을 때만.** 이웃 · 다른 사람의 기타는 모습만
- 기타와 마시멜로 꼬챙이는 동시에 못 든다 (팔 자세가 겹쳐 꼬챙이가 하늘로 솟았음)

### 장작
- **던지지 않는다.** 손을 내밀면 돌 테두리 위 장작이 불 속으로 밀려 들어가 기대 선 채 타다 사라진다 (`placeLog`)
- 가운데 장작더미는 **낮게, 서로 엇갈려 교차**(약 0.6m). 장작을 낮춰도 **불꽃 높이는 그대로**
- 둘레 돌은 **무늬 없는 단색**

### 밤하늘
- **오로라 없음**, 은하수는 아주 옅게 (하얀 연기처럼 보인다고 함)
- 별은 구 표면에 **고르게** (정육면체 점을 늘리면 머리 위가 빔), 북극성(`POLE`)을 축으로 13분에 한 바퀴
- 별자리: 실제 적경 · 적위 · 등급으로 모양을 옮김. **빛무리 공 · 한 획씩 그리기 · 이야기 문장은 빼 달라고 함.**
  별은 또렷하게, 선은 **가늘고 옅게**(누우면 0.24), 이름표는 배경 없이 옅게, **깊이 검사 켬**(텐트 천을 뚫고 보였음)

### 누웠을 때 (텐트 · 해먹)
- 아래 안내 상자는 오른쪽 아래 '일어나기' 버튼만 (`body.lying`)
- **해먹**: 두 나무 · 랜턴 · 전구 줄 · 해먹 천을 내 화면에서 숨겨 하늘을 온전히 (`hammock.decor`, `hammock.pivot`)
- **텐트**: 이웃 · 사람 · 모든 꼬마전구(`garlandObjs`) · 해먹 장식 · 데크 등을 숨김.
  시선은 모닥불 정면, 화면을 당겨(fov 28) 모닥불이 크게. 텐트 랜턴은 안쪽 뒤에(눈앞을 가리면 안 됨), 실내는 어둡게
- 일어나면 텐트 문 밖으로 나와 **비스듬한 시점**(지붕이 화면을 덮으면 안 됨)

### 모양
- 텐트는 **벨 텐트**(원통 벽 + 원뿔 지붕, 문 110° 열림, 처마 띠 · 삼각 깃발). 세모 텐트는 "그냥 세모"라고 함
- 해먹은 **해먹만**(베개 · 이불 빼 달라고 함). 줄무늬 천 + 술 장식
- 해먹 나무는 **곧은 줄기 + 3.5m 부터 둥근 잎 덩어리**. 층층 원뿔 소나무는 아래로 뾰족해서, 가지가 보이면 꺾인 기둥 같아서 둘 다 지적받음
- 풀은 **짧고 넓적하고 끝이 뭉툭한 잎 5장** (뾰족하면 "선인장 가시")
- 얼굴: 눈 반짝임은 **빛을 받는 재질**(MeshBasic 흰색은 어두운 얼굴에서 눈만 번쩍여 "무섭다")
- 호수: **고운 잔물결이 아주 느리게** + 가끔 물방울 동심원. 물 표면은 무광(roughness 0.78) — 매끈하면 달빛 반사가 하얗게 눈부심

## 4. 이미 밟은 지뢰

| 증상 | 원인 | 해결 |
|---|---|---|
| 블룸이 조용히 꺼짐 (콘솔 "블룸 생략") | 후처리 모듈이 `import 'three'` 를 하는데 이름을 못 찾음 | `index.html` 에 **importmap** (쉼터 `index.v2.html` 은 아직 없음) |
| 블룸 켜자 불꽃이 하얗게 탐 | 불꽃 판 5장이 덧셈 합성 | 불꽃 셰이더 밝기 0.6 배, 블룸 0.42 / 문턱 0.9 |
| 물을 클릭하면 물속을 걸음 | 호수 막는 타원이 0.93배라 물가 안쪽 띠가 비었음 | 타원 1.1배 + 클릭 지점이 물이면 데크 끝 / 물가로 옮김. 데크 위만 예외(`onDeck`) |
| 해먹 · 숲에서 화면이 새까맘 | 카메라가 잎 덩어리 안으로 → 가림 검사가 바깥면만 봄 | 잎을 `DoubleSide` + 나무를 `occluders` 에. 길찾기 도착은 **캠프 쪽에서 바라보는 시점**(`arriveYaw`) |
| 누운 뒤 일어나면 위에서 내려다봄 | 하늘 보던 camPitch 가 그대로 | 눕기 → 서기에서 camPitch 0.3 |
| 숨겨진 '그만하기' 버튼이 클릭을 가로챔 | 투명해도 pointer-events 살아 있음 | `#zen.show` 일 때만 클릭 |
| 불멍 끝낸 직후 문장이 패널 위에 겹침 | 사라지는 전환이 1.6초 | 숨길 땐 0.25초 |
| 휴대폰에서 앉으면 버튼이 잘림 | 버튼 6개를 한 줄 가로 스크롤 | 760px 이하에서 두 줄 |
| 셸에서 파이썬 치환이 깨짐 | heredoc 안 따옴표 · 이스케이프 | 긴 치환은 **파일로 써서** 실행, 치환마다 `assert s.count(a)==1` |

## 5. 데이터 · 네트워크

- Supabase 는 **쉼터와 같은 프로젝트 · 같은 테이블**. SQL 을 새로 실행할 필요 없음
  - 방 이름 앞에 `BUL-` (`DBROOM`), 실시간 채널은 `bulmeong:<방>`
  - 카운터는 SQL 제약(`water|cheer|happy`) 때문에 이름을 빌림: `CNT = { wood: 'water', smore: 'happy' }`
  - 저장: 풍등(kind `wish`) · 장작 수 · 마시멜로 수. **고민 태우기 글은 저장도 전송도 안 함**
- `move` 에 `pose · lift(=앉기/눕기 높이 보정) · g(기타) · rs/rl(마시멜로 굽는 중 · 익은 정도)` 를 실어 보냄 → 늦게 온 사람도 같은 모습
- `act`: wave · bow · dance · emoji · wood · burn · eat · lantern · skip · counter
- 이름 · 모습은 쉼터와 같은 localStorage 칸(`shelter:name`, `shelter:look`)을 써서 쉼터에서 고른 모습 그대로 들어옴

### 앉기 높이
자리마다 `off = 좌석 높이 − 0.42` (쉼터의 seatDrop 규약). 눕기는 높이 그대로(해먹 0.42 · 텐트 0.1).
캐릭터 루트 y = `standY + (서 있지 않으면 seatOff)`. 상대에게는 이 값을 `lift` 로 그대로 보냄.

## 6. 검증 (쉼터와 같은 방식)

`playwright-core` + 로컬 Chromium. 테스트 중엔 공용 DB 를 건드리지 않게 **혼자 모드로 강제**:
```js
await page.addInitScript(() => { let c; Object.defineProperty(window, 'SPACE_CONFIG',
  { configurable: true, get() { return c; }, set(v) { v.supabase = null; c = v; } }); });
```
- `window.__bul` (확인용) — `pos()` 내 위치, `cam()` 카메라 위치, `lake(x,z)` 호수 거리(1 = 물가), `deck(x,z)`
- 기타 소리 확인: 길이 2.4초짜리 AudioBuffer 재생 횟수를 셈 → 앉아만 있으면 0, 누른 뒤에만 늘어야 함
- **휴대폰**: `devices['iPhone 13']` 으로 시작 → 모닥불 → 앉기 → 불멍 → 해먹/텐트 눕기 → 호숫가 → 대화창까지 찍어 가림 확인
- 함께 모드는 테스트 방(`?room=CLAUDETEST`)에서 창 두 개로 — 저장되는 동작(장작 · 풍등)은 빼고

## 7. 쉼터 ↔ 불멍 오가기

- 길찾기 맨 아래 '🌲 쉼터로'(불멍) / '🔥 불멍 캠프'(쉼터) — `?room=같은 방&go=1` 로 이동, 시작 화면 생략
- 버튼 옆 '· 지금 N명' = 건너편 공간 인원 (`store.watchCount`, 함께 모드일 때만)
- 넘어갈 때 `#fade` 로 어두워지고 소리도 잦아듦. 소리가 막힌 채 도착하면 `#sound-tap` 안내
- 확인: `vercel.json` 규칙을 흉내 내는 로컬 서버로 `/` ↔ `/bulmeong/` 왕복 + file:// 왕복 둘 다
