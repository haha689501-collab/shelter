# 🔥 불멍 캠프

별이 쏟아지는 밤, 숲속 공터 한가운데 모닥불 앞에 둘러앉아 멍하니 쉬어 가는 3D 공간입니다.
쉼터(상위 폴더)와 같은 방식 — three.js 하나만 불러오고, 불꽃 · 하늘 · 소리를 전부 코드로 만듭니다.

## 실행

- `index.html` 을 더블클릭하면 바로 열립니다 (혼자 모드 또는 함께 모드).
- 배포 주소: `https://<쉼터 주소>/bulmeong/` — 쉼터 길찾기의 **🔥 불멍 캠프** 버튼으로도 들어오고, 불멍의 **🌲 쉼터로** 버튼으로 돌아갑니다
- 친구 초대: `.../bulmeong/?room=CODE` (방 코드가 곧 입장 코드)

## 공간 구성

| 장소 | 좌표 | 할 수 있는 일 |
|---|---|---|
| 모닥불 | 0, 0 | 통나무 벤치 · 캠핑 의자 10자리 · **불멍하기** · 장작 넣기 · 마시멜로 굽기 · 기타 · 고민 태우기 · 불꽃막대 |
| 텐트촌 | -12, -9 | 랜턴 켜고 끄기 · 텐트 안 침낭에 누워 쉬기 (문 밖으로 모닥불 · 별) |
| 소나무 해먹 | 15, 3 | 누우면 천천히 흔들리며 은하수 · 별똥별 |
| 호숫가 데크 | 4, 20 | 달빛 길 · 풍등 날리기(소원 저장) · 풍등 읽기 · 물수제비 · 물가에 걸터앉기 |

모닥불 이웃(NPC) 3명 (이름표 없음): 마시멜로를 굽는 이웃, 무릎에 기타를 올려 둔 이웃, 가끔 말을 거는 이웃.
기타 소리는 **내가 "기타 치기"를 눌렀을 때만** 납니다.

### 불멍하기
모닥불 자리에 앉아 **불멍하기**를 누르면 버튼이 모두 사라지고, 어깨 옆에서 불을 바라보는 화면이 됩니다.
이웃 · 의자도 숨겨 모닥불만 남고, 소리도 타닥 소리와 귀뚜라미만 남깁니다.
13초마다 짧은 문장이 바뀌고, 끝낼 때(`Esc` · "그만하기" · 걷기) "불멍 N초 했어요"로 알려 줍니다.

### 밤하늘
별은 북극성을 축으로 천천히 흐르고(약 13분에 한 바퀴), 별자리 8개(북두칠성 · 작은곰 · 카시오페이아 · 백조 · 거문고 · 전갈 · 오리온 · 사자)는
실제 별 좌표 · 밝기 · 색으로 그렸습니다. 해먹 · 텐트에 누우면 선이 한 획씩 그려지고 이름과 짧은 이야기가 떠오릅니다.

## 저장되는 것 / 안 되는 것

| 무엇 | 저장 | 비고 |
|---|---|---|
| 풍등(소원) | ✅ | `shelter_messages` 테이블, kind `wish` |
| 장작 · 마시멜로 수 | ✅ | `shelter_counters` 의 `water`(=장작) · `happy`(=마시멜로) 이름을 빌려 씀 |
| 고민 태우기 글 | ❌ | 저장도 전송도 하지 않음. 다른 사람에게는 "종이를 던지는 모습"만 보임 |
| 대화 · 움직임 · 기타 · 마시멜로 굽는 중 | ❌ | 실시간 브로드캐스트만 |

- 쉼터와 **같은 Supabase 프로젝트**를 씁니다. SQL 을 새로 실행할 필요가 없습니다.
- 같은 방 코드라도 섞이지 않도록 DB 의 방 이름 앞에 `BUL-` 를 붙입니다 (예: `BUL-MAIN`).
- 실시간 채널 이름도 `bulmeong:<방>` 으로 쉼터(`shelter:<방>`)와 분리돼 있습니다.

## 소리 (전부 WebAudio 생성)

장작 타는 바탕 소리 + 타닥 · 탁 튀는 소리(가까울수록 큼), 풀벌레, 가끔 부엉이, 호숫가 물결, 아주 작은 바람.
기타는 카플러스-스트롱 방식으로 줄 튕기는 소리를 직접 계산해 C · G · Am · F 를 칩니다.
지속음(드론)은 쓰지 않았습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (불멍 모드 `#zen` 포함) |
| `app.js` | 본체. 캐릭터 · 대화 · 모습 고르기 · 이동 규칙은 쉼터 `app.v2.js` 에서 가져옴 |
| `style.css` | 쉼터 `style.v2.css` + 맨 아래 밤 · 모닥불 색 덮어쓰기 |
| `config.js` | 이름 · 장소 · Supabase 공개 키 |
